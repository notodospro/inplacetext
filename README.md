## What it does

InPlaceText changes words that are already part of a picture. You type the text as it appears, type what it should say, and the new words are redrawn in place so the rest of the image stays the same.

It is built for flattened JPG, PNG, and WebP files when you do not have the original design file:

- Keep the original font style, color, size, lighting, shadows, and surface texture
- Works with English, Chinese, Japanese, Korean, Spanish, handwriting, and decorative lettering
- 1 free edit with no sign-up and no watermark; optional one-time credit packs (no subscription, credits never expire, failed edits auto-refunded) at https://inplacetext.com/pricing/
- Failed edits are refunded automatically
- If the same words appear more than once, drag a box around the one you want to change

## How to use it

1. Open [https://inplacetext.com/](https://inplacetext.com/) and upload a JPG, PNG, or WebP (up to 10MB).
2. Type the words as they appear in the image. Optionally drag a box around the exact line.
3. Type the replacement text and generate. Download the result with no watermark.

Type a whole word or line rather than single letters. Replacements close in length to the original usually fit more naturally.

## What not to edit

Only edit images you own or are authorized to change. Do not use the tool on identity documents, bank or payment records, invoices, tickets, or official certificates.

Opening an image does not upload it. The image and the text you typed are sent only when you generate an edit.
